PRINCE BART — DOCUMENTATION REFERENCE
====================================

Purpose
-------
This document defines how causal estimands should be named and described in the
Prince BART package documentation.

The goal is to remain STRICTLY consistent with the paper, while keeping user-facing
documentation readable and familiar.

This document is AUTHORITATIVE for terminology and wording choices.


Core constraint (non-negotiable)
--------------------------------
In the paper:

- CATE means CONDITIONAL Average Treatment Effect.
- CATE does NOT mean “average effect among compliers”.

Therefore:

- NEVER use “CATE” to refer to an average over compliers.
- NEVER use “CATE among compliers” or similar shortcuts.


Recommended documentation layers
--------------------------------

1) User-facing narrative (README, vignettes, high-level docs)
2) Function-level documentation
3) Mathematical / reference sections

Different layers may use different levels of formality, but MUST respect the
terminology rules below.


User-facing wording (preferred)
-------------------------------

The following expressions ARE ALLOWED and ENCOURAGED in narrative text:

- “average effect among compliers”
- “IV-identified effect”
- “LATE-like effect”
- “effect identified by an encouragement design”
- “average causal effect for units whose treatment status is affected by the instrument”

These phrases should be used WITHOUT introducing the term CATE.

Example:
  “The package estimates a LATE-like average effect among compliers, allowing for
   flexible effect heterogeneity.”


Connection to LATE (encouraged)
-------------------------------

It is appropriate to explicitly connect the estimand to LATE.

Recommended phrasing:
- “Under effect homogeneity, this estimand coincides with the traditional LATE.”
- “Prince BART generalizes LATE by allowing treatment effects to vary with covariates.”
- “Unlike classical LATE estimation, Prince BART models heterogeneous complier effects.”

Avoid claiming equivalence unless homogeneity is stated.


Formal estimands (reference use)
--------------------------------

The following estimands are defined in the paper and may be referenced sparingly
in documentation.

CATE(x)
-------
Conditional Average Treatment Effect.

Definition:
  E[Y(1) - Y(0) | X = x]

This term is RESERVED for conditional effects and should not be repurposed.


CATE_C(x)
---------
Conditional Average Treatment Effect among compliers.

Definition:
  E[Y(1) - Y(0) | X = x, G = c]

Use in:
- mathematical sections
- reference documentation
- clarifying footnotes


MATE_C
------
Mixed Average Treatment Effect among compliers.

Definition:
  Average of CATE_C(x) over the empirical covariate distribution of compliers.

Guidance:
- This term does NOT need to be front-and-center.
- It may be introduced once as the formal name of the estimand.
- After introduction, prefer “average effect among compliers” in prose.


MCATE_C
-------
Mixed subgroup averages of CATE_C.

Guidance:
- Use primarily when describing effect heterogeneity.
- Can be referred to descriptively as “subgroup-specific average effects among compliers”.


PATE
----
Population Average Treatment Effect.

Definition:
  Average of CATE_C(x) over a target population covariate distribution.

Use when discussing generalization.


Prohibited shortcuts
--------------------
The following are NOT allowed anywhere in the documentation:

- “CATE among compliers”
- “the CATE (complier)”
- “complier CATE” without definition
- using CATE to mean an average rather than a conditional quantity


Documentation principle
-----------------------
If a term would confuse a statistically literate user who has read the paper,
it should not be used.

Prefer clarity over brevity, and familiarity over novelty, as long as precision
is preserved.
